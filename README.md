此项目是基于Django和Vue.js3的在线招聘系统
整体项目分为三个部分：招聘平台 API 系统，招聘平台求职者前端和招聘平台 CMS 后台管理系统。

招聘平台求职者前端主要功能包括：用户注册登录、身份认证、个人信息修改、职位申请进度查询、邀请消息回复、职位搜索、公司搜索、模糊查询、分页显示、文件上传下载功能等功能模块。

招聘平台 CMS 后台管理系统的主要功能包括：超级管理员登录、公司管理员/人员登录、权限检测、公司管理、人员管理、职位管理、面试管理、邀请消息发送、模糊查询、分页显示、文件上传下载等功能模块。

 招聘平台API 系统采用最火的 Python 的网络框架 Django 开发，使用 Django REST framework 开发所有的 API ，JWT Token 实现验证登录，并且同步生成 API 的 Swagger 文档；
 前端的两个项目则是使用 Vue.js 3 框架，使用 TypeScript 语言编写，同时还使用到了最新的 Vue 全家桶技术，Vue Router 4 负责前端路由管理，Pinia 负责状态管理， Vite 负责编译项目，Axios 发送网络请求，Element-UI 负责页面布局。
